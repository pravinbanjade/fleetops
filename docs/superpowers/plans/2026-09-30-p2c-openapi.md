# FleetOps P2c — OpenAPI Document Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publish an accurate OpenAPI 3.1 document for every fleetops API route at `/api/v1/openapi.json`, commit it to the repository, and add a `fleetops --openapi` flag that prints it, so P3 can generate the web client from it.

**Architecture:**
- The API router is built with `utoipa_axum::router::OpenApiRouter`. Every route is registered through `routes!(handler)`, which takes the path from the handler's `#[utoipa::path]` annotation. The router that serves requests and the document are built from the same list, so a route cannot exist without documentation.
- Request and response types derive `utoipa::ToSchema`. utoipa reads their serde attributes, so the schemas describe the JSON serde actually reads and writes.
- `fleetops_api::openapi` adds what utoipa cannot infer:
  - the session-cookie and CSRF security schemes, applied per operation;
  - a `default` error response (`ErrorBody`) on every operation;
  - shared path parameters;
  - websocket message schemas.
- The API test suite becomes a contract test. `TestApp::send` checks every request and response against the document with a JSON Schema validator. The suite then fails on any undocumented route, any undocumented status, any response body that does not match its schema, and any accepted request body the schema would reject.

**Tech Stack:** Rust ≥1.86, axum 0.8, utoipa 5.5, and utoipa-axum 0.2 (both need Rust 1.75 or newer). jsonschema 0.58 is a dev-dependency only, with default features off.

**Spec:** `docs/superpowers/specs/2026-09-29-fleetops-core-docker-design.md`, sections §2.1 (the `fleetops-api` crate owns OpenAPI via utoipa), §2.4 and §5.1 (OpenAPI served at `/api/v1/openapi.json`), and §9 (the spec is generated at build time, and CI fails if the generated client drifts).

**Plan series for sub-project 1:**
- P1 (done): backend foundation.
- P2a (done): environments and REST resources.
- P2b (done): websocket hub and background tasks.
- **P2c (this plan):** the OpenAPI document.
- P3: web UI (including `pnpm gen:api` from this document), e2e tests, image build, CI.

## Global Constraints

- **Versions:** use utoipa `5.5` and utoipa-axum `0.2`. Do not move to utoipa 6 or utoipa-axum 0.3: both need Rust 1.88, and the workspace floor is 1.86.
- **Serving:** the document is OpenAPI 3.1.0. It is served at `/api/v1/openapi.json` without a session, with `content-type: application/json`. Its paths include the `/api/v1` prefix.
- **Registration:** every API route is registered in `routes::api()` through `routes!(...)`. After Task 4, no plain `.route(...)` calls remain.
- **Operation metadata:** every operation has a unique camelCase `operationId`, exactly one tag, and a `summary`.
  - P3's generated client uses the operationIds as function names, so renaming one is a breaking change.
- **Security:** five operations are public: `getHealth`, `getOpenApi`, `getAuthStatus`, `setup` and `login`. They declare `security(())`.
  - Every other GET needs the `session` cookie scheme (cookie `fleetops_session`).
  - Every other method needs `session` and `csrf` together (header `x-csrf-token`).
  - `openapi::secure()` applies these, so handlers don't repeat them.
- **Errors:** every error response is the JSON `ErrorBody {code, message, request_id}`, documented as each operation's `default` response. That includes rejections from axum's own extractors (Task 5).
  - `default` never documents a success. Every 2xx and 101 response is listed explicitly.
- **No wire changes:** typed structs replace `json!` bodies with identical JSON. These are `ErrorBody`, `Health`, `AuthStatus`, `ImageRemoved`, `ComposeOutcome` and `TaskStarted`.
- **Passthrough payloads:** Docker payloads passed through verbatim (inspect, `/info`, `/system/df`, history) are documented as free-form objects.
- **Committed document:** `crates/fleetops-api/openapi.json` is committed. `cargo test` fails when it differs from the code, and `make openapi` regenerates it.
- **Spec deltas (intentional):**
  - The spec says the document is "generated at build time". Here it is generated from code at runtime, by `GET /openapi.json`, `fleetops --openapi` and `make openapi`. The committed copy, together with the drift test, gives the same guarantee without a `build.rs`.
  - The websocket is documented as one path, `GET /ws` answering 101. Its frames are the component schemas `ClientMsg` and `ServerMsg`, plus the `DockerEvent`, `StatsSample`, `LogLine`, `LogOptions` and `ExecOptions` payload schemas.
  - `GET /openapi.json` documents itself, as `getOpenApi`.
  - The TS client (`pnpm gen:api`) stays in P3.

## Review Focus

1. **Malformed input that axum's own extractors reject.** Examples: a missing `?path=`, `?limit=many`, a build request that is not multipart, a plain GET on `/ws`. Each must still get the JSON `ErrorBody` the document promises, with the right status, never axum's plain text. Pinned in Task 5 (`tests/rejections.rs`).
2. **A route or status added later without documentation.** `routes!` makes an undocumented route impossible to register. `OPERATIONS` catches a silently dropped route, and the strict checker catches an undocumented status or route hit by any test. Pinned in Task 2 (`checker_rejects_mismatched_traffic`), Task 4 (`checker_rejects_undocumented_routes`) and Task 6 (`committed_document_matches_the_code`).
3. **Request schemas stricter than the server.** For example, fields with serde defaults marked required would force every client to send them. Pinned in Task 1 (`defaulted_fields_are_optional_in_requests`), and by the contract check on every accepted request in the suite (Task 2).
4. **`null` in a field the document calls non-null.** A client generated from the document would mistype it. Pinned in Task 1 (`option_fields_may_be_null`) and Task 4 (`websocket_messages_match_their_schemas`, including `exit_code: null`).
5. **`fleetops --openapi` in a container or CI.** It must print the document and exit without starting the server, binding a port or creating the data directory. Pinned in Task 6 (`openapi_flag_prints_the_document_and_exits`).

fn schema<T: PartialSchema>() -> Value {
    serde_json::to_value(T::schema()).unwrap()
}

#[test]
fn enums_use_their_wire_names() {
    assert_eq!(schema::<Role>()["enum"], json!(["admin", "user"]));
}

#[test]
fn env_status_is_tagged_by_state() {
    let s = schema::<EnvStatus>();
    let states: Vec<Value> = s["oneOf"]
        .as_array()
        .expect("oneOf")
        .iter()
        .map(|v| v["properties"]["state"]["enum"].clone())
        .collect();
    assert_eq!(states, vec![json!(["up"]), json!(["down"])]);
}

### Task 2: The document, auth/users/audit routes, and the contract checker

**Files:**
- Create: `crates/fleetops-api/src/openapi.rs`, `crates/fleetops-api/tests/common/contract.rs`, `crates/fleetops-api/tests/openapi.rs`.
- Modify: `Cargo.toml` and `crates/fleetops-api/Cargo.toml`.
- Modify: `crates/fleetops-api/src/error.rs`, `extract.rs` and `lib.rs`.
- Modify: `crates/fleetops-api/src/routes/mod.rs`, `auth.rs`, `users.rs` and `audit_log.rs`.
- Modify: `crates/fleetops-api/tests/common/mod.rs`.

**Interfaces:**
- Consumes: the Task 1 schemas, `auth::cookie::SESSION_COOKIE` and `auth::CSRF_HEADER`.
- Produces (in `fleetops_api::openapi`):
  - `API_BASE = "/api/v1"`.
  - `document(router: OpenApiRouter<S>) -> utoipa::openapi::OpenApi`: nests the router at `API_BASE`, sets `info.version` to the crate version, and runs `secure()`.
  - `json() -> &'static str`: the pretty document, built once.

//! Checks API traffic against the published OpenAPI document.
//!
//! `TestApp::send` passes every exchange of the API test suite through
//! [`check`], so the whole suite doubles as a contract test. A test fails
//! when the server answers:
//! - with a status the operation does not document (`default` covers
//!   errors only, never a success),
//! - with a JSON body that does not match the documented schema,
//! - or with a 2xx to a JSON request body the documented schema rejects.

use jsonschema::Validator;

    collections::HashMap,

pub fn doc() -> &'static Value {
    static DOC: OnceLock<Value> = OnceLock::new();
    DOC.get_or_init(|| serde_json::from_str(fleetops_api::openapi::json()).expect("valid JSON"))
}

/// One request and its response, as `TestApp::send` saw them.
pub struct Exchange<'a> {
    pub method: &'a str,
    /// The request path, without the query string.
    pub path: &'a str,
    /// The request body, when it was JSON.
    pub request: Option<&'a Value>,
    pub status: u16,
    pub content_type: Option<&'a str>,
    /// The response body: parsed JSON, a string for other bodies, or null

/// The documented path that axum routes `path` to. Like axum's router, a
/// literal segment beats a `{param}` at the same position.
pub fn route_of(path: &str) -> Option<&'static str> {
    let segs: Vec<&str> = path.split('/').collect();
    doc()["paths"]
        .as_object()?
        .keys()
        .filter_map(|tpl| {
            let t: Vec<&str> = tpl.split('/').collect();
            if t.len() != segs.len() {
                return None;
            }
            let mut rank = Vec::with_capacity(t.len());
            for (a, b) in t.iter().zip(&segs) {
                if a.starts_with('{') && a.ends_with('}') && !b.is_empty() {
                    rank.push(1);
                } else if a == b {
                    rank.push(0);
                } else {
                    return None;
                }
            }
            Some((rank, tpl.as_str()))
        })
        .min()
        .map(|(_, tpl)| tpl)
}

fn is_json(ct: Option<&str>) -> bool {
    ct.is_some_and(|c| c.starts_with("application/json"))
}

/// Validates `instance` against `schema`, which may `$ref` the document's
/// components. Compiled validators are cached under `key`.
fn validate(key: String, schema: &Value, instance: &Value) -> Result<(), String> {
    static CACHE: OnceLock<Mutex<HashMap<String, Arc<Validator>>>> = OnceLock::new();
    let cache = CACHE.get_or_init(Default::default);
    let v = {
        let mut c = cache.lock().unwrap();
        match c.get(&key) {
            Some(v) => v.clone(),
            None => {
                let mut root = schema.clone();
                root["components"] = doc()["components"].clone();
                let v = Arc::new(
                    jsonschema::validator_for(&root)
                        .map_err(|e| format!("{key}: bad schema: {e}"))?,
                );
                c.insert(key.clone(), v.clone());
                v
            }
        }
    };
    let errors: Vec<String> = v
        .iter_errors(instance)
        .map(|e| format!("{} at {}", e, e.instance_path()))
        .collect();
    if errors.is_empty() {
        Ok(())
    } else {
        Err(format!("{key}: {}\nbody: {instance:#}", errors.join("; ")))
    }
}

pub fn check(x: &Exchange) -> Result<(), String> {
    if !x.path.starts_with(fleetops_api::openapi::API_BASE) {
        return Ok(());
    }
    let what = format!("{} {} -> {}", x.method, x.path, x.status);
    let Some(tpl) = route_of(x.path) else {
        // Routes documented in later tasks are not checked yet.
        return Ok(());
    };
    let method = x.method.to_ascii_lowercase();
    let Some(op) = doc()["paths"][tpl].get(&method) else {
        return if x.status == 405 {
            Ok(())
        } else {
            Err(format!("{what}: {method} is not documented for {tpl}"))
        };
    };
    let success = (200..300).contains(&x.status);
    let documented = &op["responses"][x.status.to_string()];
    let resp = match (documented.is_null(), success) {
        (false, _) => documented,
        (true, false) => &op["responses"]["default"],
        (true, true) => return Err(format!("{what}: status not documented for {tpl}")),
    };
    let key = format!("{method} {tpl} {}", x.status);
    match resp.get("content").and_then(Value::as_object) {
        None if !x.body.is_null() => {
            return Err(format!("{what}: documented without a body, got {}", x.body))
        }
        None => {}
        Some(content) => {
            let (ct, media) = content.iter().next().expect("one media type");
            let sent = x.content_type.unwrap_or("");
            if !sent.starts_with(ct.as_str()) {
                return Err(format!("{what}: documented as {ct}, sent as {sent:?}"));
            }
            if is_json(Some(ct)) {
                validate(key.clone(), &media["schema"], x.body)?;
            }
        }
    }
    if let (true, Some(request)) = (success, x.request) {
        if let Some(schema) = op["requestBody"]["content"]["application/json"].get("schema") {
            validate(format!("{key} request"), schema, request)?;
        }
    }
    Ok(())
}
