# Sub-project 3c: Per-environment RBAC Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Per-user, per-environment `viewer`/`operator` grants, with Kubernetes grants optionally limited to a set of namespaces, enforced at one decision point and reflected in the UI.

**Architecture:** A pure `Grant` model in `fleetops-core::access` (role checks, namespace checks, list/watch filters, per-document apply check). The store keeps bindings in a rebuilt `role_bindings` table and answers `env_grant(user, env)` fresh on every call. The API resolves the grant in its three gates (`docker::ctx`, `kube::kube_for`, `ws::topics::docker_for`) and handlers apply namespace checks; the shared watch registry is untouched and each subscriber filters. An `access` broadcast ends a user's subscriptions when their access changes.

**Tech Stack:** Rust (axum 0.8, utoipa, sqlx/SQLite, kube-rs), React 19 + TanStack Query/Router, vitest, Playwright, kind.

**Spec:** `docs/superpowers/specs/2026-10-06-fleetops-rbac-design.md`

## Global Constraints

- Roles: `viewer`, `operator` (serde lowercase). Global `users.role` stays `admin` | `user`.
- `namespaces`: NULL = whole environment; each an RFC 1123 label; at most 50; deduplicated and sorted; empty array refused with "give at least one namespace, or omit for the whole cluster"; refused for Docker environments with "only a Kubernetes environment takes namespaces".
- Error texts (exact): `operator role required`; `namespace '<ns>' is not in your access`; `cluster-scoped objects are outside your access`; `admins already have full access`; websocket end message `your access changed`.
- No grant → `NotFound("environment '<name>'")`, identical to a missing environment, not audited.
- Forbidden refusals on an environment the caller can see are audited with `result = "denied"`, action `access.denied`, target type `env`, detail `{action, error}`.
- Audit actions for the management API: `access.grant`, `access.revoke`, target type `user`, target id the user id, detail `{env, role, namespaces}`.
- Upgrade backfill: every `user`-role account gets `operator`, `namespaces = NULL` on every existing environment. New environments and new users get no bindings.
- Write actions: Docker container/image/volume/network/compose mutations and exec; Kubernetes delete, scale, restart, replace, apply, exec. Everything else is read.
- Namespace-limited grants: Nodes readable (all); Namespaces readable only by name in the set; every other cluster-scoped kind and every cluster-scoped write refused.
- The shared watch registry (`ws/watches.rs`) is not changed; filtering happens per subscriber.
- Commits end with the session's attribution lines.

## Review Focus

1. A stale namespace remembered in the browser (`fleetops.ns.<env>` in localStorage) that is outside a limited grant: the list shows the 403 text and the picker still lets the user choose another namespace — not a blank page or a crash loop. (Task 9 test.)
2. An admin demoted to `user` after bindings were written for them while admin: those bindings take effect, and a demoted admin with no bindings sees no environments. (Task 2 store test, Task 3 API test.)
3. Two tabs of the same user: an `access` change ends subscriptions on both connections, not only the one that is open longest. (Task 6 test.)
4. An apply whose documents mix allowed and refused namespaces with `dry_run: true`: the refused ones are never sent, even as a dry run. (Task 4 kube unit test and Task 11 kind test.)
5. A limited user's all-namespace watch when an object moves into view by being created in an allowed namespace after the snapshot: the `added` event reaches them; one created elsewhere does not. (Task 5 test.)

```rust
//! Per-environment access (spec §2.2): what a user may do in one
//! environment, and for Kubernetes, in which namespaces. Pure: the store
//! produces grants, the API enforces them.

use crate::kube::{KubeKind, KubeList, WatchEvent};
use crate::{Error, Result};
use serde::{Deserialize, Serialize};
use std::collections::BTreeSet;
use std::str::FromStr;
use utoipa::ToSchema;

pub const NAMESPACES_MAX: usize = 50;

#[derive(Debug, Clone, Copy, PartialEq, Eq, PartialOrd, Ord, Serialize, Deserialize, ToSchema)]
#[serde(rename_all = "lowercase")]
pub enum EnvRole {
    /// Read everything the grant covers.
    Viewer,
    /// Read and change it, including exec.
    Operator,
}

impl EnvRole {
    pub fn as_str(&self) -> &'static str {
        match self {
            EnvRole::Viewer => "viewer",
            EnvRole::Operator => "operator",
        }
    }
}

impl FromStr for EnvRole {
    type Err = Error;
    fn from_str(s: &str) -> Result<Self> {
        match s {
            "viewer" => Ok(EnvRole::Viewer),
            "operator" => Ok(EnvRole::Operator),
            other => Err(Error::Invalid(format!("unknown environment role '{other}'"))),
        }
    }
}

/// One user's access to one environment.
#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize, ToSchema)]
pub struct Grant {
    pub role: EnvRole,
    /// `None` is the whole environment; otherwise the only namespaces
    /// (Kubernetes) the grant covers.
    pub namespaces: Option<BTreeSet<String>>,
}

pub fn ns_denied(ns: &str) -> Error {
    Error::Forbidden(format!("namespace '{ns}' is not in your access"))
}

pub fn cluster_scoped_denied() -> Error {
    Error::Forbidden("cluster-scoped objects are outside your access".into())
}

/// An RFC 1123 DNS label: what Kubernetes allows for namespace names.
pub fn is_dns_label(s: &str) -> bool {
    let b = s.as_bytes();
    !b.is_empty()
        && b.len() <= 63
        && b.iter().all(|c| c.is_ascii_lowercase() || c.is_ascii_digit() || *c == b'-')
        && b[0].is_ascii_alphanumeric()
        && b[b.len() - 1].is_ascii_alphanumeric()
}

pub fn normalize_namespaces(v: Vec<String>) -> Result<BTreeSet<String>> {
    if v.is_empty() {
        return Err(Error::Invalid(
            "give at least one namespace, or omit for the whole cluster".into(),
        ));
    }
    if let Some(bad) = v.iter().find(|n| !is_dns_label(n)) {
        return Err(Error::Invalid(format!("'{bad}' is not a Kubernetes namespace")));
    }
    let set: BTreeSet<String> = v.into_iter().collect();
    if set.len() > NAMESPACES_MAX {
        return Err(Error::Invalid(format!("at most {NAMESPACES_MAX} namespaces per grant")));
    }
    Ok(set)
}

/// Whether one applied document may be sent: checked after namespace
/// defaulting and before any request, dry run included.
pub fn check_doc(allowed: Option<&BTreeSet<String>>, namespaced: bool, ns: Option<&str>) -> Result<()> {
    let Some(set) = allowed else { return Ok(()) };
    match (namespaced, ns) {
        (true, Some(ns)) if set.contains(ns) => Ok(()),
        (true, Some(ns)) => Err(ns_denied(ns)),
        _ => Err(cluster_scoped_denied()),
    }
}

impl Grant {
    pub fn full(role: EnvRole) -> Self {
        Self { role, namespaces: None }
    }

    pub fn require(&self, role: EnvRole) -> Result<()> {
        if self.role >= role {
            Ok(())
        } else {
            Err(Error::Forbidden(format!("{} role required", role.as_str())))
        }
    }

    pub fn allows_ns(&self, ns: &str) -> bool {
        self.namespaces.as_ref().is_none_or(|s| s.contains(ns))
    }

    pub fn check_ns(&self, ns: &str) -> Result<()> {
        if self.allows_ns(ns) { Ok(()) } else { Err(ns_denied(ns)) }
    }

    /// A list request: one namespace must be in the set; all namespaces and
    /// the two readable cluster-scoped kinds are filtered instead.
    pub fn check_list(&self, kind: KubeKind, ns: Option<&str>) -> Result<()> {
        match ns {
            Some(ns) if !kind.cluster_scoped() => self.check_ns(ns),
            _ => Ok(()),
        }
    }

    /// One object. `ns` is `-` for cluster-scoped kinds.
    pub fn check_object(&self, kind: KubeKind, ns: &str, name: &str, write: bool) -> Result<()> {
        if self.namespaces.is_none() {
            return Ok(());
        }
        match kind {
            KubeKind::Nodes | KubeKind::Namespaces if write => Err(cluster_scoped_denied()),
            KubeKind::Nodes => Ok(()),
            KubeKind::Namespaces => self.check_ns(name),
            _ => self.check_ns(ns),
        }
    }

    fn row_visible(&self, kind: KubeKind, ns: Option<&str>, name: &str) -> bool {
        let Some(set) = &self.namespaces else { return true };
        match kind {
            KubeKind::Nodes => true,
            KubeKind::Namespaces => set.contains(name),
            _ => ns.is_some_and(|n| set.contains(n)),
        }
    }

    pub fn filter_list(&self, kind: KubeKind, mut list: KubeList) -> KubeList {
        list.rows.retain(|r| self.row_visible(kind, r.namespace.as_deref(), &r.name));
        list
    }

    /// The event as this grant sees it; `None` when it is about an object
    /// outside the grant.
    pub fn filter_event(&self, kind: KubeKind, ev: WatchEvent) -> Option<WatchEvent> {
        match ev {
            WatchEvent::Snapshot { mut rows } => {
                rows.retain(|r| self.row_visible(kind, r.namespace.as_deref(), &r.name));
                Some(WatchEvent::Snapshot { rows })
            }
            WatchEvent::Added { row } | WatchEvent::Modified { row }
                if !self.row_visible(kind, row.namespace.as_deref(), &row.name) =>
            {
                None
            }
            WatchEvent::Deleted { namespace, name }
                if !self.row_visible(kind, namespace.as_deref(), &name) =>
            {
                None
            }
            other => Some(other),
        }
    }
}
```

```rust
//! The single authorization decision point (spec §2.2). Global actions
//! need the admin role; environment actions need a grant from the store,
//! read fresh on every request.

use crate::{auth::extract::CurrentUser, AppState};
use fleetops_core::access::{EnvRole, Grant};
use fleetops_core::env::Environment;
use fleetops_core::{now_unix, Error, Result, Role, User};
use fleetops_store::NewAudit;
use std::sync::Arc;

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum Action {
    /// See an environment and its status.
    EnvRead,
    /// Create, change or delete environments.
    EnvManage,
    DockerRead,
    DockerWrite,
    KubeRead,
    KubeWrite,
}

impl Action {
    fn needs(self) -> Option<EnvRole> {
        match self {
            Action::EnvRead | Action::DockerRead | Action::KubeRead => Some(EnvRole::Viewer),
            Action::DockerWrite | Action::KubeWrite => Some(EnvRole::Operator),
            Action::EnvManage => None,
        }
    }

    fn as_str(self) -> &'static str {
        match self {
            Action::EnvRead => "env.read",
            Action::EnvManage => "env.manage",
            Action::DockerRead => "docker.read",
            Action::DockerWrite => "docker.write",
            Action::KubeRead => "k8s.read",
            Action::KubeWrite => "k8s.write",
        }
    }
}

pub fn authorize_global(user: &User, action: Action) -> Result<()> {
    match action {
        Action::EnvManage if user.role != Role::Admin => {
            Err(Error::Forbidden("admin role required".into()))
        }
        _ => Ok(()),
    }
}

/// No grant reads exactly like a missing environment.
pub fn authorize_env(grant: Option<&Grant>, env_name: &str, action: Action) -> Result<()> {
    let g = grant.ok_or_else(|| Error::NotFound(format!("environment '{env_name}'")))?;
    match action.needs() {
        Some(role) => g.require(role),
        None => Err(Error::Forbidden("admin role required".into())),
    }
}

/// Resolves `name`, checks `action` against the caller's grant, and
/// returns both. A refusal on a visible environment is audited.
pub async fn env_access(
    s: &AppState,
    cu: &CurrentUser,
    name: &str,
    action: Action,
) -> Result<(Arc<dyn Environment>, Grant)> {
    let env = s.envs.get(name)?;
    let grant = s.store.env_grant(cu.user.id, env.id()).await?;
    let r = authorize_env(grant.as_ref(), name, action);
    deny_audited(s, cu, env.id(), action.as_str(), r).await?;
    Ok((env, grant.expect("authorized")))
}

/// Passes `r` through; a `Forbidden` is first written to the audit log.
pub async fn deny_audited<T>(
    s: &AppState,
    cu: &CurrentUser,
    env_id: i64,
    what: &str,
    r: Result<T>,
) -> Result<T> {
    if let Err(e @ Error::Forbidden(_)) = &r {
        let entry = NewAudit {
            ts: now_unix(),
            user_id: Some(cu.user.id),
            environment_id: Some(env_id),
            action: "access.denied",
            target_type: Some("env"),
            target_id: Some(&env_id.to_string()),
            result: "denied",
            detail: Some(serde_json::json!({ "action": what, "error": e.to_string() })),
        };
        if let Err(e) = s.store.insert_audit(&entry).await {
            tracing::error!(error = %e, "failed to write audit log");
        }
    }
```

```rust
    pub env_kind: String,

    fn from(b: &BindingRecord) -> Self {
        Self { env_id: b.environment_id, env_name: b.env_name.clone(), env_kind: b.env_kind.clone(), role: b.grant.role, namespaces: ns_list(b) }

impl From<&BindingRecord> for EnvAccessEntry {
    fn from(b: &BindingRecord) -> Self {

    }

async fn audit(s: &AppState, admin: i64, action: &str, user_id: i64, env_id: i64, detail: serde_json::Value) {

        action,
        target_type: Some("user"),
        target_id: Some(&id),
        result: "success",
        detail: Some(detail),

pub async fn list_user(State(s): State<AppState>, _a: AdminUser, ApiPath(id): ApiPath<i64>) -> ApiResult<Json<Vec<AccessEntry>>> {

#[utoipa::path(put, path = "/users/{id}/access/{env_id}", operation_id = "setUserAccess", tag = "users",
    summary = "Grant or change a user's access to an environment",
    params(("id" = i64, Path, description = "User id"), ("env_id" = i64, Path, description = "Environment id")),
    request_body = SetAccess, responses((status = 200, description = "The grant", body = AccessEntry)))]
pub async fn set(
    State(s): State<AppState>,
    AdminUser(admin): AdminUser,
    ApiPath((id, env_id)): ApiPath<(i64, i64)>,
    ApiJson(body): ApiJson<SetAccess>,
) -> ApiResult<Json<AccessEntry>> {
    if s.store.get_user(id).await?.role == Role::Admin {
        return Err(Error::Invalid("admins already have full access".into()).into());
    }
    let ns = body.namespaces.map(normalize_namespaces).transpose()?;
    let b = s.store.set_binding(id, env_id, body.role, ns.as_ref(), now_unix()).await?;
    let entry = AccessEntry::from(&b);
    audit(&s, admin.user.id, "access.grant", id, env_id, json!({"env": b.env_name, "role": body.role, "namespaces": entry.namespaces})).await;
    s.hubs.access_changed(id);
    Ok(Json(entry))
}

#[utoipa::path(delete, path = "/users/{id}/access/{env_id}", operation_id = "revokeUserAccess", tag = "users",
    summary = "Revoke a user's access to an environment",
    params(("id" = i64, Path, description = "User id"), ("env_id" = i64, Path, description = "Environment id")),
    responses((status = 204, description = "Revoked (or there was nothing to revoke)")))]
pub async fn revoke(
    State(s): State<AppState>,
    AdminUser(admin): AdminUser,
    ApiPath((id, env_id)): ApiPath<(i64, i64)>,
) -> ApiResult<StatusCode> {
    s.store.get_user(id).await?;
    let env = s.store.get_environment(env_id).await?;
    if s.store.delete_binding(id, env_id).await? {

    }

}
```

```ts
import { useQuery } from "@tanstack/react-query";
import type { EnvRole, Grant } from "@/api/gen/types.gen";
import { envsQuery } from "./queries";

export interface EnvAccess {
  role: EnvRole;
  canWrite: boolean;
  /** Null: the whole environment. */
  namespaces: string[] | null;
}

/** The caller's access from an environment row; no field means full access (the server enforces either way). */
export function accessOf(env: { access?: Grant | null } | undefined): EnvAccess {
  const role = env?.access?.role ?? "operator";
  return { role, canWrite: role === "operator", namespaces: env?.access?.namespaces ?? null };
}

export function useEnvAccess(env?: string): EnvAccess {
  const { data } = useQuery(envsQuery);
  return accessOf(data?.find((e) => e.name === env));
}
```
