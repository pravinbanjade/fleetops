# Sub-project 3d: Helm releases — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Kubernetes environments list Helm releases with history, masked values, masked manifest and notes, and an operator can roll a release back or uninstall it, natively and compatibly with the Helm CLI.

**Architecture:** `fleetops-kube` reads and writes Helm 3's own storage (`sh.helm.release.v1.*` Secrets: base64 → gzip → JSON) through the existing kube-rs client, so it works over a kubeconfig and through the agent tunnel alike. Rollback applies a three-way JSON merge patch (current revision → target revision) per object, after a dry run reviewed in the UI; the release record is written the way Helm writes it. The API adds five routes behind the 3c grants; the web adds a releases list, a release page and a plan dialog.

**Tech Stack:** Rust (kube-rs 4.2, k8s-openapi 0.28, axum 0.8, utoipa), `flate2` (new), `jiff` (already in the tree through k8s-openapi), React + TanStack Router/Query, vitest, Playwright, kind + the `helm` CLI (tests only).

**Spec:** `docs/superpowers/specs/2026-10-07-fleetops-helm-design.md`

## Global Constraints

- Helm 3 Secrets storage driver only: Secrets of type `helm.sh/release.v1`, labels `owner=helm`, `name`, `status`, `version`.
- No `helm` binary in any shipped image. The CI image gets a pinned `helm` for tests only.
- No decoded value or Secret data reaches the browser, a log line or an audit row. Values keys masked when the lowercased key contains any of: `password`, `passwd`, `secret`, `token`, `key`, `credential`, `auth`, `cert`, `private`. The mask is `fleetops_core::kube::MASK` (`••••`).
- Nothing is written without a dry run first; every commit carries `expected_current`.
- Revision description on success: `Rollback to N (FleetOps; hooks not run)`. Every plan carries the note `Chart hooks are not run by FleetOps.`
- 409 text when the release moved or is pending: `release changed; review again`.
- The releases list polls every 10 s while the page is visible.
- One new crate dependency: `flate2`. (`jiff` is added to the workspace at the version k8s-openapi already pulls in, so nothing new compiles.)
- Every existing test passes; `OPERATIONS` in `crates/fleetops-api/tests/openapi.rs` goes from 76 to 81.

## Review Focus

1. **A release with more than 100 manifest documents** must roll back and uninstall; the 3b apply cap (`APPLY_MAX_DOCS`) must not apply. Test: Task 4, `a_large_manifest_is_not_capped`.
2. **One corrupt or legacy (un-gzipped) release Secret** must not break the list: the row shows `unreadable`, the others list normally. Tests: Task 2, `plain_json_without_gzip_decodes` and `garbage_is_an_error_not_a_panic`; Task 6, `an_unreadable_release_is_a_row_not_an_error`.
3. **An object deleted by hand before a rollback** must be recreated, not reported as a 404. Test: Task 7, the `kubectl delete deployment` step before the first rollback.
4. **Credentials in odd places in values** (nested in lists, upper-case keys such as `TLS_CERT`, `apiKey`, a whole map under `auth:`) must be masked. Test: Task 3, `secretish_keys_are_masked_anywhere`.
5. **A manifest Secret that uses `stringData`, or a document that does not parse,** must never be shown raw. Test: Task 3, `manifest_secrets_and_unparseable_documents_are_hidden`.

//! Helm releases (sub-project 3d): what the API shows of a release and the
//! plan of a rollback or uninstall. `fleetops-kube` reads and writes Helm's
//! own storage; nothing here holds an unmasked value.

use crate::kube::ApplyError;
use serde::{Deserialize, Serialize};
use utoipa::ToSchema;

/// The status of a release whose stored record cannot be decoded.
pub const UNREADABLE: &str = "unreadable";
/// Said on every rollback and uninstall plan.
pub const HOOKS_NOTE: &str = "Chart hooks are not run by FleetOps.";
/// The refusal when the release moved since it was reviewed, or another
/// operation is in progress.
pub const CHANGED: &str = "release changed; review again";

/// `pending-install`, `pending-upgrade`, `pending-rollback`: another
/// operation holds the release.
pub fn is_pending(status: &str) -> bool {
    status.starts_with("pending-")
}

/// One release, at its latest revision.
#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize, ToSchema)]
pub struct HelmRelease {
    pub name: String,
    pub namespace: String,
    pub revision: u32,
    /// Helm's status (`deployed`, `failed`, `pending-upgrade`, …), or `unreadable`.
    pub status: String,
    pub chart: String,
    pub chart_version: String,
    pub app_version: String,
    /// Last deployed, unix seconds; 0 when unknown.
    pub updated: i64,
    /// Why the record cannot be read, when the status is `unreadable`.
    pub error: Option<String>,
}

/// One revision in a release's history.
#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize, ToSchema)]
pub struct HelmRevision {
    pub revision: u32,
    pub status: String,
    pub chart_version: String,
    pub app_version: String,
    pub description: String,
    pub updated: i64,
}

/// One revision in full, masked.
#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize, ToSchema)]
pub struct ReleaseDetail {
    pub release: HelmRelease,
    pub description: String,
    pub notes: String,
    /// User-supplied values as YAML, credential-looking keys masked; empty when none.
    pub values: String,
    /// The rendered manifest, Secret values masked.
    pub manifest: String,
}

#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize, ToSchema)]
#[serde(rename_all = "lowercase")]
pub enum HelmChange {
    /// Patched from the current revision's form to the target's.
    Patch,
    /// In the target revision only.
    Create,
    /// In the current revision only, or removed by an uninstall.
    Delete,
    /// Would be deleted, but annotated `helm.sh/resource-policy: keep`.
    Keep,
}

/// What a rollback or uninstall does (or did) to one object.
#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize, ToSchema)]
pub struct HelmObjectChange {
    pub api_version: String,
    pub kind: String,
    pub namespace: Option<String>,
    pub name: String,
    pub change: HelmChange,
    /// The live object before, cleaned and masked; `None` when absent.
    pub before: Option<String>,
    /// The object after (or as it would be); `None` for a delete or keep.
    pub after: Option<String>,
    pub error: Option<ApplyError>,
}

/// A rollback or uninstall: the dry run's plan, or a commit's results.
#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize, ToSchema)]
pub struct HelmPlan {
    /// The latest revision this was computed against; a commit sends it
    /// back as `expected_current`.
    pub current: u32,
    /// Commit of a rollback only: the revision written.
    pub revision: Option<u32>,
    /// Commit only: the release's status afterwards (`deployed`, `failed`
    /// or `uninstalled`).
    pub status: Option<String>,
    pub changes: Vec<HelmObjectChange>,
    pub note: String,
}

//! Helm 3's Secrets storage driver (spec §2.2): one Secret per revision,
//! `data.release` holding base64 of gzip of the release JSON.

use base64::Engine;
use fleetops_core::helm::{HelmRelease, HelmRevision, UNREADABLE};
use serde::{Deserialize, Serialize};
use serde_json::{Map, Value};
use std::collections::BTreeMap;
use std::io::{Read, Write};

pub const SECRET_TYPE: &str = "helm.sh/release.v1";
pub const OWNER_SELECTOR: &str = "owner=helm";
const GZIP_MAGIC: [u8; 2] = [0x1f, 0x8b];
const B64: base64::engine::GeneralPurpose = base64::engine::general_purpose::STANDARD;

/// A release record. Fields FleetOps does not read are kept in `rest`, so
/// a record written back loses nothing Helm stored.
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct Release {
    pub name: String,
    pub namespace: String,
    pub version: u32,
    pub info: Info,
    #[serde(default, skip_serializing_if = "Value::is_null")]
    pub chart: Value,
    #[serde(default, skip_serializing_if = "Value::is_null")]
    pub config: Value,
    #[serde(default, skip_serializing_if = "String::is_empty")]
    pub manifest: String,
    #[serde(flatten)]
    pub rest: Map<String, Value>,
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct Info {
    #[serde(default)]
    pub status: String,
    #[serde(default, skip_serializing_if = "String::is_empty")]
    pub description: String,
    #[serde(default, skip_serializing_if = "String::is_empty")]
    pub notes: String,
    #[serde(default, skip_serializing_if = "Option::is_none")]
    pub first_deployed: Option<String>,
    #[serde(default, skip_serializing_if = "Option::is_none")]
    pub last_deployed: Option<String>,
    #[serde(flatten)]
    pub rest: Map<String, Value>,
}

/// A record from a Secret's `data.release` bytes.
pub fn decode(raw: &[u8]) -> Result<Release, String> {
    let text: Vec<u8> = raw.iter().copied().filter(|b| !b.is_ascii_whitespace()).collect();
    let bytes = B64.decode(text).map_err(|e| format!("not base64: {e}"))?;
    let json = if bytes.starts_with(&GZIP_MAGIC) {
        let mut out = Vec::new();
        flate2::read::GzDecoder::new(&bytes[..])
            .read_to_end(&mut out)
            .map_err(|e| format!("not gzip: {e}"))?;
        out
    } else {
        bytes
    };
    serde_json::from_slice(&json).map_err(|e| format!("not a Helm release: {e}"))
}

/// The bytes for `data.release`, as Helm writes them.
pub fn encode(r: &Release) -> Vec<u8> {
    let json = serde_json::to_vec(r).expect("a release always serialises");

//! What a release shows (spec §2.4): values with credential-looking keys
//! masked, and the manifest with Secret values masked. Best effort for
//! values: a credential under an innocent key is shown.

use fleetops_core::kube::MASK;
use serde_json::Value;

const SECRETISH: [&str; 9] = [
    "password", "passwd", "secret", "token", "key", "credential", "auth", "cert", "private",
];

fn secretish(key: &str) -> bool {
    let k = key.to_ascii_lowercase();
    SECRETISH.iter().any(|s| k.contains(s))
}

/// Replaces every non-null value under a credential-looking key, whole
/// subtrees included.
pub fn mask_values(v: &mut Value) {
    match v {
        Value::Object(map) => {
            for (k, val) in map.iter_mut() {
                if secretish(k) && !val.is_null() {
                    *val = MASK.into();
                } else {
                    mask_values(val);
                }
            }
        }
        Value::Array(items) => items.iter_mut().for_each(mask_values),
        _ => {}
    }
}

/// Masked values as YAML; empty when there are none.
pub fn values_yaml(config: &Value) -> String {
    if config.is_null() || config.as_object().is_some_and(|m| m.is_empty()) {
        return String::new();
    }
    let mut v = config.clone();
    mask_values(&mut v);
    serde_saphyr::to_string(&v).unwrap_or_else(|e| format!("# cannot render: {e}\n"))
}

/// The manifest with each Secret's values masked. Other documents are
/// shown as rendered; one that does not parse is replaced, since it might
/// be a Secret.
pub fn manifest(m: &str) -> String {
    let mut out = String::new();
    for doc in crate::apply::documents(m) {
        if doc.trim().is_empty() {
            continue;
        }
        let comments: String = doc
            .lines()
            .take_while(|l| l.starts_with('#'))
            .map(|l| format!("{l}\n"))
            .collect();
        out.push_str("---\n");
        match serde_saphyr::from_str::<Value>(&doc) {
            Ok(mut v) if v.get("kind").and_then(Value::as_str) == Some("Secret") => {
                for field in ["data", "stringData"] {
                    if let Some(map) = v.get_mut(field).and_then(Value::as_object_mut) {
                        map.values_mut().for_each(|x| *x = MASK.into());
                    }
                }
                out.push_str(&comments);
                out.push_str(
                    &serde_saphyr::to_string(&v)
                        .unwrap_or_else(|_| "# (Secret hidden)\n".into()),
                );
            }
            Ok(_) => out.push_str(&doc),
            Err(_) => {
                out.push_str(&comments);
                out.push_str("# (document could not be parsed; hidden)\n");
            }
        }
    }
    out
}

//! What a rollback or uninstall will do (spec §3.1, §4), worked out from
//! the manifests alone; `ops` runs it against the cluster.

use crate::apply::{split_all, Doc};
use fleetops_core::helm::HelmChange;
use fleetops_core::Result;
use serde_json::{Map, Value};
use std::collections::BTreeMap;

const KEEP: &str = "helm.sh/resource-policy";

/// Helm's `UninstallOrder` (pkg/releaseutil/kind_sorter.go). Kinds not
/// listed go last, by name.
const UNINSTALL_ORDER: [&str; 36] = [
    "APIService", "Ingress", "IngressClass", "Service", "CronJob", "Job", "StatefulSet",
    "HorizontalPodAutoscaler", "Deployment", "ReplicaSet", "ReplicationController", "Pod",
    "DaemonSet", "RoleBindingList", "RoleBinding", "RoleList", "Role", "ClusterRoleBindingList",
    "ClusterRoleBinding", "ClusterRoleList", "ClusterRole", "CustomResourceDefinition",
    "PersistentVolumeClaim", "PersistentVolume", "StorageClass", "ConfigMap", "SecretList",
    "Secret", "ServiceAccount", "PodDisruptionBudget", "PodSecurityPolicy", "LimitRange",
    "ResourceQuota", "NetworkPolicy", "Namespace", "PriorityClass",
];

pub struct Step {
    pub doc: Doc,
    pub change: HelmChange,
    /// The merge patch, for `Patch` only.
    pub patch: Option<Value>,
}

/// (group, kind, namespace or the release's, name): how an object in one
/// revision is matched to the same object in another.
type Key = (String, String, String, String);

fn key(d: &Doc, release_ns: &str) -> Key {
    let group = d.api_version.split_once('/').map(|(g, _)| g).unwrap_or("");
    (
        group.to_string(),
        d.kind.clone(),
        d.namespace.clone().unwrap_or_else(|| release_ns.to_string()),
        d.name.clone(),
    )
}

fn kept(d: &Doc) -> bool {
    d.value.pointer("/metadata/annotations").and_then(|a| a.get(KEEP)).and_then(Value::as_str)
        == Some("keep")
}

fn rank(kind: &str) -> usize {
    UNINSTALL_ORDER.iter().position(|k| *k == kind).unwrap_or(UNINSTALL_ORDER.len())
}

fn removal(doc: Doc) -> Step {
    let change = if kept(&doc) { HelmChange::Keep } else { HelmChange::Delete };
    Step { doc, change, patch: None }
}

fn in_uninstall_order(mut docs: Vec<Doc>) -> Vec<Doc> {
    docs.sort_by(|a, b| (rank(&a.kind), &a.kind, &a.name).cmp(&(rank(&b.kind), &b.kind, &b.name)));
    docs
}

/// A JSON merge patch turning `base` into `target`: changed keys take
/// `target`'s value (lists whole), keys only in `base` become null, equal
/// keys are left out.
pub fn merge_patch(base: &Value, target: &Value) -> Value {
    match (base, target) {
        (Value::Object(b), Value::Object(t)) => {
            let mut out = Map::new();
            for (k, tv) in t {
                match b.get(k) {
                    Some(bv) if bv == tv => {}
                    Some(bv @ Value::Object(_)) if tv.is_object() => {
                        out.insert(k.clone(), merge_patch(bv, tv));
                    }
                    _ => {
                        out.insert(k.clone(), tv.clone());
                    }
                }
            }
            for k in b.keys().filter(|k| !t.contains_key(*k)) {
                out.insert(k.clone(), Value::Null);
            }
            Value::Object(out)
        }
        _ => target.clone(),
    }
}

pub fn rollback_steps(current: &str, target: &str, release_ns: &str) -> Result<Vec<Step>> {
    let mut now: BTreeMap<Key, Doc> = split_all(current)?
        .into_iter()
        .map(|d| (key(&d, release_ns), d))
        .collect();
    let mut steps = Vec::new();
    for doc in split_all(target)? {
        match now.remove(&key(&doc, release_ns)) {
            Some(old) => {
                let patch = merge_patch(&old.value, &doc.value);
                steps.push(Step { doc, change: HelmChange::Patch, patch: Some(patch) });
            }
            None => steps.push(Step { doc, change: HelmChange::Create, patch: None }),
        }
    }
    steps.extend(in_uninstall_order(now.into_values().collect()).into_iter().map(removal));
    Ok(steps)
}

pub fn uninstall_steps(current: &str) -> Result<Vec<Step>> {
    Ok(in_uninstall_order(split_all(current)?).into_iter().map(removal).collect())
}

/// The ownership metadata Helm checks before it will upgrade an object.
pub fn adopt(value: &mut Value, release: &str, release_ns: &str) {
    let meta = value
        .as_object_mut()
        .expect("a document is an object")
        .entry("metadata")
        .or_insert_with(|| Value::Object(Map::new()));
    let set = |meta: &mut Value, field: &str, k: &str, v: &str| {
        let m = meta
            .as_object_mut()
            .expect("metadata is an object")
            .entry(field)
            .or_insert_with(|| Value::Object(Map::new()));
        if let Some(m) = m.as_object_mut() {
            m.insert(k.into(), v.into());
        }
    };
    set(meta, "labels", "app.kubernetes.io/managed-by", "Helm");
    set(meta, "annotations", "meta.helm.sh/release-name", release);
    set(meta, "annotations", "meta.helm.sh/release-namespace", release_ns);
}

/// Longest description written to a failed revision.
const DESCRIPTION_MAX: usize = 1000;

fn unreadable_err(e: String) -> Error {
    Error::Upstream { status: 422, message: format!("the release record cannot be read: {e}") }
}

impl KubeClient {
    fn release_secrets(&self, ns: Option<&str>) -> Api<Secret> {
        match ns {
            Some(ns) => Api::namespaced(self.client.clone(), ns),
            None => Api::all(self.client.clone()),
        }
    }

    /// (namespace, name, version) of every release Secret matching `selector`.
    async fn release_metas(&self, ns: Option<&str>, selector: &str) -> Result<Vec<(String, String, u32)>> {
        let lp = ListParams::default().labels(selector);
        let list = timed(self.release_secrets(ns).list_metadata(&lp)).await?;
        Ok(list
            .items
            .into_iter()
            .filter_map(|m| {
                let l = m.metadata.labels?;
                Some((m.metadata.namespace?, l.get("name")?.clone(), l.get("version")?.parse().ok()?))
            })
            .collect())
    }

    async fn read_release(&self, ns: &str, name: &str, version: u32) -> Result<Release> {
        let s = timed(self.release_secrets(Some(ns)).get_opt(&storage::secret_name(name, version)))
            .await?
            .ok_or_else(|| Error::NotFound(format!("revision {version} of release '{name}' not found")))?;
        let raw = s.data.as_ref().and_then(|d| d.get("release")).map(|b| b.0.clone()).unwrap_or_default();
        storage::decode(&raw).map_err(unreadable_err)
    }

    async fn latest(&self, ns: &str, name: &str) -> Result<Release> {
        let sel = format!("{},name={name}", storage::OWNER_SELECTOR);
        let v = self
            .release_metas(Some(ns), &sel)
            .await?
            .into_iter()
            .map(|(_, _, v)| v)
            .max()
            .ok_or_else(|| Error::NotFound(format!("release '{name}' not found")))?;
        self.read_release(ns, name, v).await
    }

    /// Creates (`create`) or replaces the Secret holding `r`.
    async fn write_release(&self, r: &Release, create: bool) -> Result<()> {
        let api = self.release_secrets(Some(&r.namespace));
        let name = storage::secret_name(&r.name, r.version);
        let mut s = if create {
            Secret { type_: Some(storage::SECRET_TYPE.into()), ..Secret::default() }
        } else {
            timed(api.get(&name)).await?
        };
        s.metadata.name = Some(name.clone());
        s.metadata.namespace = Some(r.namespace.clone());
        s.metadata.labels = Some(storage::labels(r));
        s.data = Some([("release".to_string(), ByteString(storage::encode(r)))].into());
        let pp = PostParams { dry_run: false, field_manager: Some(FIELD_MANAGER.into()) };
        if create {
            timed(api.create(&pp, &s)).await.map_err(|e| match e {
                Error::Conflict(_) => Error::Conflict(CHANGED.into()),
                e => e,
            })?;
        } else {
            timed(api.replace(&name, &pp, &s)).await?;
        }
        Ok(())
    }

    /// The resource of every step, after namespace defaulting, refusing
    /// the whole action when `allowed` does not cover an object.
    async fn resolve_steps(
        &self,
        steps: &mut [plan::Step],
        release_ns: &str,
        allowed: Option<&BTreeSet<String>>,
    ) -> Result<Vec<Result<ApiResource>>> {
        let mut out = Vec::with_capacity(steps.len());
        for s in steps.iter_mut() {
            match self.resolve(&s.doc.api_version, &s.doc.kind).await {
                Ok((ar, namespaced)) => {
                    crate::apply::set_namespace(&mut s.doc, namespaced, release_ns);
                    fleetops_core::access::check_doc(allowed, namespaced, s.doc.namespace.as_deref())?;
                    out.push(Ok(ar));
                }
                // A kind the cluster does not serve: scope unknown, so a
                // limited grant cannot be sure it covers it.
                Err(_) if allowed.is_some() => {
                    return Err(fleetops_core::access::cluster_scoped_denied());
                }
                Err(e) => out.push(Err(e)),
            }
        }
        Ok(out)
    }

    /// Runs one step (or its dry run) and reports it.
    async fn run_step(
        &self,
        step: &mut plan::Step,
        ar: Result<ApiResource>,
        release: &str,
        release_ns: &str,
        dry_run: bool,
    ) -> HelmObjectChange {
        let mut ch = HelmObjectChange {
            api_version: step.doc.api_version.clone(),
            kind: step.doc.kind.clone(),
            namespace: step.doc.namespace.clone(),
            name: step.doc.name.clone(),
            change: step.change,
            before: None,
            after: None,
            error: None,
        };
        let r: Result<(Option<String>, Option<String>)> = async {
            let ar = ar?;
            let api: Api<DynamicObject> = match &step.doc.namespace {
                Some(ns) => Api::namespaced_with(self.client.clone(), ns, &ar),
                None => Api::all_with(self.client.clone(), &ar),
            };
            let live = timed(api.get_opt(&step.doc.name)).await?.map(|o| serde_json::to_value(o).unwrap_or_default());
            match (step.change, live) {
                (HelmChange::Keep, live) => Ok((live.map(cleaned).map(|v| crate::mask::to_yaml(&v)).transpose()?, None)),
                (HelmChange::Delete, None) => Ok((None, None)),
                (HelmChange::Delete, Some(live)) => {
                    let dp = DeleteParams { dry_run, ..DeleteParams::default() };
                    timed(api.delete(&step.doc.name, &dp)).await?;
                    Ok((Some(crate::mask::to_yaml(&cleaned(live))?), None))
                }
                (HelmChange::Patch, Some(live)) => {
                    let pp = PatchParams { dry_run, field_manager: Some(FIELD_MANAGER.into()), ..PatchParams::default() };
                    let patch = step.patch.clone().unwrap_or_default();
                    let out = timed(api.patch(&step.doc.name, &pp, &Patch::Merge(&patch))).await?;
                    let (_, before, after) = outcome(Some(live), serde_json::to_value(out).unwrap_or_default())?;
                    Ok((before, Some(after)))
                }
                (HelmChange::Create, Some(_)) => Err(Error::Conflict(format!(
                    "{} '{}' already exists outside this release",
                    step.doc.kind, step.doc.name
                ))),
                // Created, or recreated after being deleted by hand.
                (HelmChange::Patch | HelmChange::Create, None) => {
                    plan::adopt(&mut step.doc.value, release, release_ns);
                    let obj: DynamicObject = serde_json::from_value(step.doc.value.clone())
                        .map_err(|e| Error::Invalid(format!("not a Kubernetes object: {e}")))?;
                    let pp = PostParams { dry_run, field_manager: Some(FIELD_MANAGER.into()) };
                    let out = timed(api.create(&pp, &obj)).await?;
                    let (_, _, after) = outcome(None, serde_json::to_value(out).unwrap_or_default())?;
                    Ok((None, Some(after)))
                }
            }
        }
        .await;
        match r {
            Ok((before, after)) => {
                ch.before = before;
                ch.after = after;
            }
            Err(e) => ch.error = Some(ApplyError::from(&e)),
        }
        ch
    }

    async fn run_steps(
        &self,
        steps: &mut [plan::Step],
        resources: Vec<Result<ApiResource>>,
        release: &str,
        release_ns: &str,
        dry_run: bool,
    ) -> Vec<HelmObjectChange> {
        let mut out = Vec::with_capacity(steps.len());
        for (step, ar) in steps.iter_mut().zip(resources) {
            out.push(self.run_step(step, ar, release, release_ns, dry_run).await);
        }
        out
    }

    /// The release's latest revision, refusing a pending one and, for a
    /// commit, one that is not `expected`.
    async fn current(&self, ns: &str, name: &str, expected: u32, dry_run: bool) -> Result<Release> {
        let cur = self.latest(ns, name).await?;
        if is_pending(&cur.info.status) || (!dry_run && cur.version != expected) {
            return Err(Error::Conflict(CHANGED.into()));
        }
        Ok(cur)
    }

    pub(crate) async fn helm_list_impl(&self, ns: Option<&str>) -> Result<Vec<HelmRelease>> {
        let metas = self.release_metas(ns, storage::OWNER_SELECTOR).await?;
        let mut out = Vec::new();
        for (ns, name, v) in storage::latest_versions(metas) {
            out.push(match self.read_release(&ns, &name, v).await {
                Ok(r) => storage::summary(&r),
                Err(Error::Upstream { status: 422, message }) => storage::unreadable(&name, &ns, v, message),
                Err(e) => return Err(e),
            });
        }
        Ok(out)
    }

    pub(crate) async fn helm_get_impl(&self, ns: &str, name: &str, revision: Option<u32>) -> Result<ReleaseDetail> {
        let r = match revision {
            Some(v) => self.read_release(ns, name, v).await?,
            None => self.latest(ns, name).await?,
        };
        Ok(ReleaseDetail {
            release: storage::summary(&r),
            description: r.info.description.clone(),
            notes: r.info.notes.clone(),
            values: mask::values_yaml(&r.config),
            manifest: mask::manifest(&r.manifest),
        })
    }

    pub(crate) async fn helm_history_impl(&self, ns: &str, name: &str) -> Result<Vec<HelmRevision>> {
        let sel = format!("{},name={name}", storage::OWNER_SELECTOR);
        let mut versions: Vec<u32> = self.release_metas(Some(ns), &sel).await?.into_iter().map(|(_, _, v)| v).collect();
        if versions.is_empty() {
            return Err(Error::NotFound(format!("release '{name}' not found")));
        }
        versions.sort_unstable();
        let mut out = Vec::with_capacity(versions.len());
        for v in versions {
            out.push(match self.read_release(ns, name, v).await {
                Ok(r) => storage::revision(&r),
                Err(Error::Upstream { status: 422, message }) => HelmRevision {
                    revision: v,
                    status: fleetops_core::helm::UNREADABLE.into(),
                    chart_version: String::new(),
                    app_version: String::new(),
                    description: message,
                    updated: 0,
                },
                Err(e) => return Err(e),
            });
        }
        Ok(out)
    }

    pub(crate) async fn helm_rollback_impl(
        &self,
        ns: &str,
        name: &str,
        to: u32,
        expected: u32,
        dry_run: bool,
        allowed: Option<&BTreeSet<String>>,
    ) -> Result<HelmPlan> {
        let mut cur = self.current(ns, name, expected, dry_run).await?;
        if to == cur.version {
            return Err(Error::Invalid(format!("revision {to} is already the current one")));
        }
        let target = self.read_release(ns, name, to).await?;
        let mut steps = plan::rollback_steps(&cur.manifest, &target.manifest, ns)?;
        let resources = self.resolve_steps(&mut steps, ns, allowed).await?;
        let mut plan = HelmPlan {
            current: cur.version,
            revision: None,
            status: None,
            changes: vec![],
            note: HOOKS_NOTE.into(),
        };
        if dry_run {
            plan.changes = self.run_steps(&mut steps, resources, name, ns, true).await;
            return Ok(plan);
        }
        // Helm's own rollback record: the target's chart, values and
        // manifest at the next version, pending until the objects are done.
        let mut next = target.clone();
        next.version = cur.version + 1;
        next.info.status = "pending-rollback".into();
        next.info.description = format!("Rollback to {to}");
        next.info.first_deployed = cur.info.first_deployed.clone();
        next.info.last_deployed = Some(storage::now());
        self.write_release(&next, true).await?;
        plan.changes = self.run_steps(&mut steps, resources, name, ns, false).await;
        let failed: Vec<String> = plan
            .changes
            .iter()
            .filter_map(|c| c.error.as_ref().map(|e| format!("{} {}: {}", c.kind, c.name, e.message)))
            .collect();
        if failed.is_empty() {
            next.info.status = "deployed".into();
            next.info.description = format!("Rollback to {to} (FleetOps; hooks not run)");
            self.write_release(&next, false).await?;
            cur.info.status = "superseded".into();
            self.write_release(&cur, false).await?;
        } else {
            next.info.status = "failed".into();
            next.info.description = truncate(format!("Rollback to {to} failed: {}", failed.join("; ")));
            self.write_release(&next, false).await?;
        }
        plan.revision = Some(next.version);
        plan.status = Some(next.info.status.clone());
        Ok(plan)
    }

    pub(crate) async fn helm_uninstall_impl(
        &self,
        ns: &str,
        name: &str,
        expected: u32,
        dry_run: bool,
        allowed: Option<&BTreeSet<String>>,
    ) -> Result<HelmPlan> {
        let mut cur = self.current(ns, name, expected, dry_run).await?;
        let mut steps = plan::uninstall_steps(&cur.manifest)?;
        let resources = self.resolve_steps(&mut steps, ns, allowed).await?;
        let mut plan = HelmPlan {
            current: cur.version,
            revision: None,
            status: None,
            changes: vec![],
            note: HOOKS_NOTE.into(),
        };
        if dry_run {
            plan.changes = self.run_steps(&mut steps, resources, name, ns, true).await;
            return Ok(plan);
        }
        cur.info.status = "uninstalling".into();
        self.write_release(&cur, false).await?;
        plan.changes = self.run_steps(&mut steps, resources, name, ns, false).await;
        let failed: Vec<String> = plan
            .changes
            .iter()
            .filter_map(|c| c.error.as_ref().map(|e| format!("{} {}: {}", c.kind, c.name, e.message)))
            .collect();
        if failed.is_empty() {
            let sel = format!("{},name={name}", storage::OWNER_SELECTOR);
            let api = self.release_secrets(Some(ns));
            for (_, _, v) in self.release_metas(Some(ns), &sel).await? {
                match timed(api.delete(&storage::secret_name(name, v), &DeleteParams::default())).await {
                    Ok(_) | Err(Error::NotFound(_)) => {}
                    Err(e) => return Err(e),
                }
            }
            plan.status = Some("uninstalled".into());
        } else {
            cur.info.status = "failed".into();
            cur.info.description = truncate(format!("Uninstall failed: {}", failed.join("; ")));
            self.write_release(&cur, false).await?;
            plan.status = Some("failed".into());
        }
        Ok(plan)
    }
}

fn truncate(mut s: String) -> String {
    if s.len() > DESCRIPTION_MAX {
        let mut cut = DESCRIPTION_MAX;
        while !s.is_char_boundary(cut) {
            cut -= 1;
        }
        s.truncate(cut);
        s.push('…');
    }
    s
}

    fn helm_write(&self, dry_run: bool, expected: u32, allowed: Option<&BTreeSet<String>>, revision: Option<u32>) -> Result<HelmPlan> {
        for (namespaced, ns) in self.helm_objects.lock().unwrap().iter() {
            fleetops_core::access::check_doc(allowed, *namespaced, ns.as_deref())?;
        }
        let mut plan = self.helm_plan.lock().unwrap().clone().expect("script helm_plan first");
        if !dry_run {

            }
            plan.revision = revision;
            plan.status.get_or_insert_with(|| if revision.is_some() { "deployed".into() } else { "uninstalled".into() });

        Ok(plan)

//! `/envs/{env}/k8s/helm/…`: Helm releases in one Kubernetes environment
//! (spec 3d §6).

use super::kube::{access_hint, agent_level, check_name, check_namespace, kube_for, with_hint, KubeCtx};
use crate::{auth::extract::CurrentUser, authz::Action, extract::{ApiJson, ApiPath}, ApiResult, AppState};
use axum::{extract::{Query, State}, Json};
use fleetops_core::helm::{HelmPlan, HelmRelease, HelmRevision, ReleaseDetail};
use fleetops_core::{now_unix, Result};
use fleetops_store::NewAudit;
use serde::Deserialize;
use utoipa::{IntoParams, ToSchema};

#[derive(Deserialize, IntoParams)]
#[into_params(parameter_in = Path)]
pub struct ReleasesPath {
    /// Environment name.
    pub env: String,
}

#[derive(Deserialize, IntoParams)]
#[into_params(parameter_in = Path)]
pub struct ReleasePath {
    pub env: String,
    /// The release's namespace.
    pub ns: String,
    /// Release name.
    pub name: String,
}

impl ReleasePath {
    fn checked(&self) -> Result<()> {
        check_namespace(&self.ns)?;
        if self.ns == "-" {
            return Err(fleetops_core::Error::Invalid("a release always has a namespace".into()));
        }
        check_name(&self.name)
    }
    fn target(&self) -> String {
        format!("{}/{}", self.ns, self.name)
    }
}

#[derive(Deserialize, IntoParams)]
#[into_params(parameter_in = Query)]
pub struct ReleasesQuery {
    /// Omit for all namespaces.
    pub namespace: Option<String>,
}

#[derive(Deserialize, IntoParams)]
#[into_params(parameter_in = Query)]
pub struct RevisionQuery {
    /// Omit for the latest.
    pub revision: Option<u32>,
}

#[derive(Deserialize, ToSchema)]
pub struct RollbackBody {
    pub revision: u32,
    /// The latest revision the plan was reviewed against.
    pub expected_current: u32,
    pub dry_run: bool,
}

#[derive(Deserialize, ToSchema)]
pub struct UninstallBody {
    pub expected_current: u32,
    pub dry_run: bool,
}

#[utoipa::path(get, path = "/envs/{env}/k8s/helm/releases", operation_id = "listHelmReleases", tag = "helm",
    summary = "Helm releases at their latest revision", params(ReleasesPath, ReleasesQuery),
    responses((status = 200, description = "Releases", body = [HelmRelease])))]
pub async fn list(
    State(s): State<AppState>,
    cu: CurrentUser,
    ApiPath(p): ApiPath<ReleasesPath>,
    Query(q): Query<ReleasesQuery>,
) -> ApiResult<Json<Vec<HelmRelease>>> {
    let ns = q.namespace.as_deref().filter(|n| !n.is_empty());
    if let Some(ns) = ns {
        check_namespace(ns)?;
    }
    let k8 = kube_for(&s, &cu, &p.env, Action::KubeRead).await?;
    if let Some(ns) = ns {
        crate::authz::deny_audited(&s, &cu, k8.env.id(), "k8s.read", k8.grant.check_ns(ns)).await?;
    }
    let rows = k8.ops.helm_list(ns).await?;
    Ok(Json(rows.into_iter().filter(|r| k8.grant.allows_ns(&r.namespace)).collect()))
}

async fn readable(s: &AppState, cu: &CurrentUser, p: &ReleasePath) -> Result<KubeCtx> {
    p.checked()?;
    let k8 = kube_for(s, cu, &p.env, Action::KubeRead).await?;
    crate::authz::deny_audited(s, cu, k8.env.id(), "k8s.read", k8.grant.check_ns(&p.ns)).await?;
    Ok(k8)
}

#[utoipa::path(get, path = "/envs/{env}/k8s/helm/releases/{ns}/{name}", operation_id = "getHelmRelease", tag = "helm",
    summary = "One revision of a release: chart, status, masked values and manifest, notes", params(ReleasePath, RevisionQuery),
    responses((status = 200, description = "The revision", body = ReleaseDetail)))]
pub async fn get(
    State(s): State<AppState>,
    cu: CurrentUser,
    ApiPath(p): ApiPath<ReleasePath>,
    Query(q): Query<RevisionQuery>,
) -> ApiResult<Json<ReleaseDetail>> {
    let k8 = readable(&s, &cu, &p).await?;
    Ok(Json(k8.ops.helm_get(&p.ns, &p.name, q.revision).await?))
}

    summary = "Every stored revision, oldest first", params(ReleasePath),

pub async fn history(

    ApiPath(p): ApiPath<ReleasePath>,

    Ok(Json(k8.ops.helm_history(&p.ns, &p.name).await?))

async fn writable(s: &AppState, cu: &CurrentUser, p: &ReleasePath) -> Result<KubeCtx> {
    p.checked()?;
    let k8 = kube_for(s, cu, &p.env, Action::KubeWrite).await?;
    crate::authz::deny_audited(s, cu, k8.env.id(), "k8s.write", k8.grant.check_ns(&p.ns)).await?;
    Ok(k8)
}

/// Adds the agent's access-level hint to each object the cluster refused.
async fn hinted(s: &AppState, k8: &KubeCtx, mut plan: HelmPlan) -> HelmPlan {
    let level = agent_level(s, &k8.env).await;
    if let Some(hint) = access_hint(level.as_deref()) {
        for e in plan.changes.iter_mut().filter_map(|c| c.error.as_mut()).filter(|e| e.code == "forbidden") {
            e.message = with_hint(std::mem::take(&mut e.message), Some(hint));
        }
    }
    plan
}

/// One row per committed rollback or uninstall. Never values.
async fn audit(s: &AppState, cu: &CurrentUser, env_id: i64, action: &str, target: &str, detail: serde_json::Value, ok: bool) {
    let entry = NewAudit {
        ts: now_unix(),
        user_id: Some(cu.user.id),
        environment_id: Some(env_id),
        action,
        target_type: Some("helm"),
        target_id: Some(target),
        result: if ok { "success" } else { "failure" },
        detail: Some(detail),
    };
    if let Err(e) = s.store.insert_audit(&entry).await {
        tracing::error!(error = %e, "failed to write audit log");
    }
}

#[utoipa::path(post, path = "/envs/{env}/k8s/helm/releases/{ns}/{name}/rollback", operation_id = "rollbackHelmRelease", tag = "helm",
    summary = "Plan or commit a rollback to an earlier revision", params(ReleasePath), request_body = RollbackBody,
    responses((status = 200, description = "The plan, or what was done", body = HelmPlan)))]
pub async fn rollback(
    State(s): State<AppState>,
    cu: CurrentUser,
    ApiPath(p): ApiPath<ReleasePath>,
    ApiJson(body): ApiJson<RollbackBody>,
) -> ApiResult<Json<HelmPlan>> {
    let k8 = writable(&s, &cu, &p).await?;
    let r = k8.ops
        .helm_rollback(&p.ns, &p.name, body.revision, body.expected_current, body.dry_run, k8.grant.namespaces.as_ref())
        .await;
    let r = crate::authz::deny_audited(&s, &cu, k8.env.id(), "k8s.write", r).await;
    if !body.dry_run {
        let (ok, detail) = match &r {
            Ok(plan) => (
                plan.status.as_deref() == Some("deployed"),
                serde_json::json!({"from": body.expected_current, "to": body.revision, "revision": plan.revision, "status": plan.status}),
            ),
            Err(e) => (false, serde_json::json!({"from": body.expected_current, "to": body.revision, "error": e.to_string()})),
        };
        audit(&s, &cu, k8.env.id(), "helm.rollback", &p.target(), detail, ok).await;
    }
    Ok(Json(hinted(&s, &k8, r?).await))
}

#[utoipa::path(post, path = "/envs/{env}/k8s/helm/releases/{ns}/{name}/uninstall", operation_id = "uninstallHelmRelease", tag = "helm",
    summary = "Plan or commit uninstalling a release", params(ReleasePath), request_body = UninstallBody,

    let r = crate::authz::deny_audited(&s, &cu, k8.env.id(), "k8s.write", r).await;

        };
        audit(&s, &cu, k8.env.id(), "helm.uninstall", &p.target(), detail, ok).await;
    }
    Ok(Json(hinted(&s, &k8, r?).await))
}

//! Helm interop against a real kind cluster with the real `helm` CLI:
//! `make test-kube`. FleetOps' rollbacks and uninstalls must leave a
//! history the CLI can carry on from.
#![cfg(feature = "kube-it")]

mod common;

use common::NS;
use fleetops_core::helm::CHANGED;
use fleetops_core::kube::{KubeOps, MASK};
use fleetops_core::Error;
use k8s_openapi::api::{apps::v1::Deployment, core::v1::ConfigMap};
use kube::api::{Api, DeleteParams};
use std::process::Command;

fn release() -> &'static str {
    if std::env::var_os("FLEETOPS_IT_TUNNEL").is_some() { "demo-tunnel" } else { "demo-direct" }
}

fn chart() -> String {
    format!("{}/../../scripts/helm-it-chart", env!("CARGO_MANIFEST_DIR"))
}

/// Runs `helm` against kind; panics with its output on failure.
fn helm(args: &[&str]) -> String {
    let out = Command::new("helm")
        .args(args)
        .args(["--namespace", NS])
        .env("KUBECONFIG", common::dir().join("kubeconfig"))
        .output()
        .expect("helm is required for the Helm suite (brew install helm)");
    let text = format!("{}{}", String::from_utf8_lossy(&out.stdout), String::from_utf8_lossy(&out.stderr));
    assert!(out.status.success(), "helm {args:?}: {text}");
    text
}

fn history() -> serde_json::Value {
    serde_json::from_str(&helm(&["history", release(), "-o", "json"])).unwrap()
}

#[tokio::test]
async fn rollback_and_uninstall_leave_a_history_helm_can_continue() {
    let ops = common::ops();
    let name = release();
    let _ = Command::new("helm").args(["uninstall", name, "--namespace", NS, "--ignore-not-found", "--wait"])
        .env("KUBECONFIG", common::dir().join("kubeconfig")).status();
    helm(&["install", name, &chart()]);
    helm(&["upgrade", name, &chart(), "--set", "extra=true", "--set", "note=hello"]);

    // Listed, with the chart; values masked.
    let rows = ops.helm_list(Some(NS)).await.unwrap();
    let row = rows.iter().find(|r| r.name == name).expect("listed");
    assert_eq!((row.revision, row.status.as_str(), row.chart.as_str()), (2, "deployed", "demo"));
    let d = ops.helm_get(NS, name, None).await.unwrap();
    assert!(d.values.contains("note") && !d.values.contains("hunter2"), "{}", d.values);
    assert_eq!(ops.helm_history(NS, name).await.unwrap().len(), 2);

    // A deployment deleted by hand is recreated, not a 404.
    let deps: Api<Deployment> = Api::namespaced(common::kube_client(), NS);
    deps.delete(name, &DeleteParams::default()).await.unwrap();
    common::eventually("the deployment to go", || async { deps.get_opt(name).await.unwrap().is_none() }).await;

    // Dry run first: nothing changes.
    let plan = ops.helm_rollback(NS, name, 1, 2, true, None).await.unwrap();
    assert_eq!(plan.current, 2);
    assert!(plan.changes.iter().all(|c| c.error.is_none()), "{:?}", plan.changes);
    let cms: Api<ConfigMap> = Api::namespaced(common::kube_client(), NS);
    assert!(cms.get_opt(&format!("{name}-extra")).await.unwrap().is_some());

    // A stale commit is refused.
    let stale = ops.helm_rollback(NS, name, 1, 1, false, None).await.unwrap_err();
    assert!(matches!(&stale, Error::Conflict(m) if m == CHANGED), "{stale}");

    // Roll back to 1: the annotation and the ConfigMap go, the deployment is back.
    let done = ops.helm_rollback(NS, name, 1, 2, false, None).await.unwrap();
    assert_eq!((done.revision, done.status.as_deref()), (Some(3), Some("deployed")), "{:?}", done.changes);
    assert!(cms.get_opt(&format!("{name}-extra")).await.unwrap().is_none());
    let dep = deps.get(name).await.unwrap();
    assert!(dep.metadata.annotations.unwrap_or_default().get("fleetops.dev/note").is_none());
    let h = history();
    assert_eq!(h[2]["revision"], 3);

import { useMutation, useQueryClient } from "@tanstack/react-query";
import { useEffect, useState } from "react";

import { errorMessage } from "@/lib/errors";

export type HelmAction = { kind: "rollback"; revision: number } | { kind: "uninstall" };

/** Plans a rollback or uninstall (dry run), shows it, and commits against the reviewed revision. */
export default function HelmPlanDialog({ env, ns, name, action, onClose }: {
  env: string; ns: string; name: string; action: HelmAction; onClose: () => void;
}) {
  const qc = useQueryClient();
  const [typed, setTyped] = useState("");
  const send = async (dry_run: boolean, expected_current: number): Promise<HelmPlan> => {
    const path = { env, ns, name };
    const r = action.kind === "rollback"
      ? await rollbackHelmRelease({ path, body: { revision: action.revision, expected_current, dry_run } })
      : await uninstallHelmRelease({ path, body: { expected_current, dry_run } });
    return r.data as HelmPlan;
  };
  const review = useMutation({ mutationFn: () => send(true, 0), meta: { inline: true } });
  const commit = useMutation({
    mutationFn: (current: number) => send(false, current),
    meta: { inline: true },
    onSettled: () => qc.invalidateQueries({ queryKey: ["env", env, "helm"] }),
  });
  useEffect(() => { review.mutate(); }, []); // eslint-disable-line react-hooks/exhaustive-deps
  const plan = commit.data ?? review.data;
  const verb = action.kind === "rollback" ? "Roll back" : "Uninstall";
  const title = action.kind === "rollback" ? `Roll back ${name} to revision ${action.revision}` : `Uninstall ${name}`;
  const ready = review.data && !commit.data && (action.kind === "rollback" || typed === name);
  const changed = commit.error && errorMessage(commit.error).includes("review again");
  return (
    <Dialog open onOpenChange={(o) => !o && onClose()}>
      <DialogContent className="max-w-3xl">
        <DialogHeader>
          <DialogTitle>{title}</DialogTitle>
          <DialogDescription>{plan?.note ?? "Working out what would change…"}</DialogDescription>
        </DialogHeader>
        {review.error && <p role="alert" className="text-sm text-state-fail">{errorMessage(review.error)}</p>}
        {commit.data && (
          <p role="status" className="text-sm">
            {action.kind === "rollback"
              ? `Revision ${commit.data.revision} is ${commit.data.status}.`
              : commit.data.status === "uninstalled" ? `${name} is uninstalled.` : `Uninstall ${commit.data.status}.`}
          </p>
        )}
        <ul className="grid max-h-[55vh] gap-3 overflow-auto">
          {plan?.changes.map((c) => (
            <li key={`${c.kind}/${c.namespace ?? "-"}/${c.name}`} className="grid gap-1">
              <span className="text-sm font-medium">{c.change} {c.kind} {c.name}</span>
              {c.error
                ? <span role="alert" className="text-sm text-state-fail">{c.error.message}</span>
                : c.change !== "keep" && <DiffView label={`${c.kind} ${c.name}`} before={c.before} after={c.after} />}
            </li>
          ))}
        </ul>
        {action.kind === "uninstall" && review.data && !commit.data && (
          <div className="grid gap-1">
            <Label htmlFor="helm-confirm">Type {name} to confirm</Label>
            <Input id="helm-confirm" value={typed} onChange={(e) => setTyped(e.target.value)} autoComplete="off" />
          </div>
        )}
        {commit.error && <p role="alert" className="text-sm text-state-fail">{errorMessage(commit.error)}</p>}
        <DialogFooter>
          {changed && (
            <Button variant="outline" onClick={() => { commit.reset(); review.mutate(); }}>Review again</Button>
          )}
          <Button variant="outline" onClick={onClose}>{commit.data ? "Close" : "Cancel"}</Button>
          {!commit.data && (
            <Button variant={action.kind === "uninstall" ? "destructive" : "default"} disabled={!ready || commit.isPending}
              onClick={() => review.data && commit.mutate(review.data.current)}>
              {verb}
            </Button>
          )}
        </DialogFooter>
      </DialogContent>
    </Dialog>
  );
}

            <dl className="grid grid-cols-[max-content_1fr] gap-x-6 gap-y-1 text-sm">
              <dt>Chart</dt><dd>{r.chart} {r.chart_version}</dd>
              <dt>App version</dt><dd>{r.app_version}</dd>

            </dl>
          )}
        </TabsContent>
        <TabsContent value="history">
          <table aria-label="Revisions" className="w-full text-sm">
            <thead><tr><th className="text-left">Revision</th><th className="text-left">Status</th><th className="text-left">Chart</th><th className="text-left">App</th><th className="text-left">Description</th><th className="text-left">Updated</th><th /></tr></thead>
            <tbody>
              {history.data?.slice().reverse().map((h) => (
                <tr key={h.revision}>
                  <td>{h.revision}</td>
                  <td><HelmStatus status={h.status} /></td>
                  <td>{h.chart_version}</td>
                  <td>{h.app_version}</td>
                  <td>{h.description}</td>
                  <td>{h.updated ? formatAgo(h.updated) : ""}</td>
                  <td>
                    {canWrite && r && h.revision !== r.revision && h.status !== "unreadable" && (
                      <Button variant="outline" size="sm" onClick={() => setAction({ kind: "rollback", revision: h.revision })}>
                        Roll back to {h.revision}
                      </Button>
                    )}
                  </td>
                </tr>
              ))}
            </tbody>
          </table>
        </TabsContent>
        <TabsContent value="values">
          <p className="mb-2 text-xs text-muted-foreground">Keys that look like credentials are masked.</p>
          <Text label="Values" text={detail.data?.values ?? ""} empty="No values were supplied." />
        </TabsContent>
        <TabsContent value="manifest"><Text label="Manifest" text={detail.data?.manifest ?? ""} empty="The manifest is empty." /></TabsContent>
        <TabsContent value="notes"><Text label="Notes" text={detail.data?.notes ?? ""} empty="This chart has no notes." /></TabsContent>
      </Tabs>
    </Page>
  );
}
